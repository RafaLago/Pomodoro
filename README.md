# Pomodori Clock

A dark-themed Pomodoro timer desktop app built with Python and CustomTkinter.

## Features

- Customizable focus and break durations (in minutes)
- Input validation for positive integer minute values
- Work and break mode transitions with popup notifications
- Pause, resume, and reset controls
- Daily completed focus session counter
- Automatic `.ico` generation from `pomodoro.png` for the window icon

## Tech Stack

- **Python 3**
- **CustomTkinter** — modern dark UI components
- **Pillow (`PIL`)** — image loading and icon conversion
- **Tkinter (`messagebox`)** — completion and validation dialogs
